# Forgot password

**Article ID:** KB-ACC-002
**Category:** Account
**Keywords:** forgot password, reset password, change password

## Symptoms
The user cannot remember their password.

## Resolution steps
1. Verify the user's username.
2. Check the account status (tool: check_account_status).
3. Run reset_password if the account is active or locked.
4. Remind the user to choose a new password of at least 12 characters.

## When to escalate
If the user is not found in the directory, ask them to confirm the username; if still not found, create a ticket.
