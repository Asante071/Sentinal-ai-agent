# Outlook is slow or freezing

**Article ID:** KB-EML-002
**Category:** Email
**Keywords:** outlook slow, freezing, not responding, large mailbox

## Symptoms
Outlook takes a long time to open or stops responding.

## Resolution steps
1. Check mailbox usage (tool: check_email_service). Very large mailboxes slow Outlook.
2. If usage is high, archive old mail (tool: fix_email_issue).
3. Ask the user to restart Outlook in safe mode if the problem continues.

## When to escalate
If the problem continues after archiving, create a ticket for a profile rebuild.
