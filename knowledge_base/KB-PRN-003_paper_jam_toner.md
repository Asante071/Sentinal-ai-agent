# Paper jam or toner problem

**Article ID:** KB-PRN-003
**Category:** Printer
**Keywords:** paper jam, toner, out of paper, hardware

## Symptoms
The printer displays a paper jam, low toner or other physical error.

## Resolution steps
1. Check the printer status (tool: check_printer_status).
2. Run troubleshoot_printer once. Remote fixes cannot clear physical faults.
3. If HARDWARE_FAULT is returned, tell the user an on-site technician is needed.

## When to escalate
Create a ticket with the printer ID and location, then escalate.
