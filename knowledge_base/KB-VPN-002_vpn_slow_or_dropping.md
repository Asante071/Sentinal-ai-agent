# VPN is slow or keeps dropping

**Article ID:** KB-VPN-002
**Category:** VPN
**Keywords:** vpn slow, drops, disconnects, timeout

## Symptoms
VPN connects but drops every few minutes or internal apps are very slow.

## Resolution steps
1. Check the VPN session state (tool: check_vpn_status).
2. Restart the VPN session (tool: restart_vpn).
3. Ask the user to switch from Wi-Fi to a wired or stronger connection.
4. Ask the user to close bandwidth-heavy applications (video streaming, large downloads).

## When to escalate
If drops continue after a restart, create a ticket with the time and location of drops and escalate to Network support.
